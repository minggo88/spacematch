## 0. `dist` 와 서버 `www`

- 로컬 `npm run build` → 결과는 **`dist/`** (도구 기본값).
- 운영 웹 루트는 보통 **`www`**, **`public_html`** 등 — **`dist/` 안 내용 전체**를 그 루트로 복사·동기화한다.
- PHP는 **`www/api/...`** 에서 `/api/...` 로 서빙된다(호스팅 구조에 따름).
- `public/api/...` 수정 시 **`dist/api/...`도 동일 내용**으로 맞춘 뒤, 서버에는 실제로 쓰는 경로만 올려도 된다.
