# Deploy — 2026-05-31

## 1. 채팅 FAB 닫기 버튼 위치 오류 수정

**증상:** 채팅 모달이 열리면 FAB 버튼이 X 아이콘으로 바뀌어 `fixed bottom-*`에 떠 있어 보내기 버튼 및 모달 헤더 X 버튼과 중복 겹침  
**원인:** FAB 버튼이 열림/닫힘 두 가지 역할을 겸했는데, 채팅 모달 헤더에 이미 독립적인 X 닫기 버튼이 존재  
**조치:** 채팅 열린 상태(X)일 때 모바일 위치를 `bottom-6` → `top-16`으로 변경 (모달 `top-20` 바로 위). 데스크탑은 `lg:top-auto lg:bottom-10` 유지  
**파일:** `src/components/Layout.jsx`  
**배포:** `npm run build` → `www/index.html` + `www/assets/` 업로드
