## 0. `dist` 와 서버 `www`

- 로컬 `npm run build` → 결과는 **`dist/`**.
- 운영 웹 루트(`www` 등)에는 **`dist/` 내용**을 복사한다.
- 프론트 변경은 빌드 후 `index.html` + `assets/**`를 **같은 빌드 세트로** 올린다.
- PHP 변경은 `public/api/...` 기준으로 수정 후 서버에는 `www/api/...`에 반영한다.

---

## 1. 수정된 파일 목록

### 1.1 셀러 입점 신청 — 상태 배지 한 줄

| 로컬 | FTP |
|------|-----|
| `src/pages/seller/SellerApplications.jsx` | *(빌드 산출물)* |
| `dist/index.html` | `www/index.html` |
| `dist/assets/SellerApplications-*.js` (+ 동일 빌드의 `dist/assets/**` 전체) | `www/assets/**` |

**설명**

- 우측 상단 상태 pill(심사중·승인·거절·취소): `inline-flex items-center shrink-0 self-start whitespace-nowrap`
- 헤더 행: `gap-2`, 왼쪽 `min-w-0 flex-1`로 긴 공간명과 배지가 한 줄 유지

**빌드**

```bash
cd spacematch
npm run build
```

- **주의:** `index.html`만 올리고 `assets`를 안 바꾸면 해시 불일치·예전 JS가 동작한다. **같은 빌드의 `index.html` + `assets/` 전체** 권장.

### 1.2 회원 탈퇴 (status=withdrawn)

| 로컬 | FTP |
|------|-----|
| `public/api/auth/withdraw.php` | `www/api/auth/withdraw.php` |
| `public/api/auth/login.php` | `www/api/auth/login.php` |
| `public/api/auth/me.php` | `www/api/auth/me.php` |
| `src/context/AuthContext.jsx` | *(빌드 산출물)* |
| `src/pages/seller/SellerProfile.jsx` | *(빌드 산출물)* |
| `src/pages/vendor/VendorProfile.jsx` | *(빌드 산출물)* |

**설명**

- 탈퇴 시 `users.status = 'withdrawn'`으로 업데이트하고 즉시 세션을 파기한다.
- 로그인(`login.php`)과 세션 확인(`me.php`)에서 `withdrawn` 계정을 차단한다.
- 프로필 화면에 “회원 탈퇴” 버튼을 추가하고, **2번(confirm)으로 재확인**한다.
