## 2. 관리자 베뉴 등록 UX (이번 수정)

- **등록 버튼** 클릭 시 모달 위 **「베뉴 등록중입니다…」** 오버레이 + 버튼 비활성화
- **성공** 시 등록 모달 **즉시 닫힘** → **「등록되었습니다」** 확인 모달
- **중복 클릭 방지**: `venueSubmitLockRef` + `submitting` 상태 유지(성공 시 모달 닫힘까지)
- **필수값 누락** 시 빨간 안내(이름·주소 검색·이용료)

|------|--------|--------|
| 카카오 지오코딩 | **생략** | 요청 중 수행 |

## 3. 배포 후 확인 — [/admin/venues](https://spacematch.net/admin/venues)

1. 새 공간 등록 → **베뉴 등록** → 1~2초 내 로딩 → 모달 닫힘 → **등록되었습니다** 모달
2. 목록에 새 행 추가
3. 등록 중 버튼·배경 클릭 **무반응**(중복 등록 없음)
4. 주소 미입력 시 **필수 안내** 표시
