## 업로드 파일 목록

### ① PHP — FTP 즉시 업로드 (빌드 불필요)

| 로컬 경로 | 서버 FTP 경로 |
|-----------|--------------|
| `public/api/db_connect.php` | `www/api/db_connect.php` |
| `public/api/users/get_host_public.php` | `www/api/users/get_host_public.php` |
| `public/api/users/browse_hosts.php` | `www/api/users/browse_hosts.php` |

### ② ENV — 서버 루트에 배치 (웹 루트 밖)

| 파일 | 서버 배치 위치 |
|------|--------------|
| `.env` (프로젝트 루트) | `www/` **상위** 디렉토리 |

> ⚠️ `www/.env` 절대 금지. cPanel 환경변수 또는 `.htaccess SetEnv`로 대체 가능.

### ③ React 빌드 결과물 — index.html + assets + locales 세트로 업로드

| 로컬 경로 | 서버 FTP 경로 |
|-----------|--------------|
| `dist/index.html` | `www/index.html` |
| `dist/assets/` (전체 폴더) | `www/assets/` (전체 교체) |
| `dist/locales/` (전체 폴더) | `www/locales/` (전체 교체) |

> ⚠️ `locales/`는 `assets/` 안에 포함되지 않는 별도 폴더 — 반드시 함께 업로드.  
> ⚠️ `index.html`만 올리거나 `assets/`만 올리면 해시 불일치 오류 발생.

## 변경 파일 상세

### React 수정 파일 (빌드 필요)

| 파일 | 변경 내용 |
|------|----------|
| `src/pages/seller/SellerProfile.jsx` | 회원탈퇴 버튼 → 저장 버튼 아래 소형 버튼으로 이동, 카드 섹션 제거; **Host Account 배지 옆 공유 버튼 추가** (링크복사·카카오·네이티브, createPortal, host 전용) |
| `src/pages/seller/SellerHostDirectory.jsx` | 공유 기능 완전 구현 — 링크복사·카카오·네이티브 공유, `createPortal`로 드롭다운 렌더링(모달 z-index 우회), `?host=` 파라미터 단일 호스트 뷰 + 모달 자동 오픈, 모달 닫기 시 shareMenu 리셋; **공간 서브팝업에 입점신청 버튼 추가** (셀러·관리자 전용, /seller 페이지 동일 모달 기능); **`isApplied` 로직 수정** — 상태 필터(`pending/approved`) 제거, `/seller` 페이지와 동일하게 모든 신청 상태 포함 체크; **PREMIUM 섹션 모바일 반응형 수정** — 뱃지 `absolute` → inline `flex justify-between`, 외부 컨테이너 `overflow-hidden` 분리(헤더만 적용), `hover:-translate-y-1` 제거, 반응형 패딩(`p-4 sm:p-5`)/폰트(`text-base sm:text-lg`)/아바타(`w-12 sm:w-14`); **호스트 카드 프로필 이미지 표시** — PREMIUM·일반 카드 아바타 영역에 `profile_image` 있으면 `<img>`, 없으면 이니셜 fallback |
| `src/pages/community/CommunityPage.jsx` | 인기 글 랭킹 클릭 수정 — `goToPopularPost` else 브랜치를 `setSearchParams({post:id})`로 교체, 기존 `?post=ID` 핸들러 위임(API에서 글 직접 fetch → 목록 상단 inject → 자동 스크롤·펼침) |
| `public/api/users/browse_hosts.php` + `dist/api/users/browse_hosts.php` | `profile_image`, `description` SELECT 추가 (SHOW COLUMNS 동적 체크, fallback 포함); venue 옵셔널 컬럼에 `event_periods` 추가 |
| `src/pages/HostSharePage.jsx` | 신규 — 로그인 불필요 공개 공유 페이지 (`/host-share/:id`) |
| `src/components/NotificationPrompt.jsx` | 세션당 1회만 표시 (sessionStorage 적용, 타이머 재표시 제거) |
| `src/components/Layout.jsx` | footer 항상 페이지 맨 아래 — main을 `flex-1 flex flex-col min-h-screen`으로, content div에 `flex-1` 적용. 페이지 body가 스크롤, sidebar `h-screen sticky top-0` 유지. fixed/sticky 없이 자연스러운 흐름으로 footer가 항상 최하단 |
| `src/App.jsx` | `/host-share/:id` 라우트 추가 |
| `src/pages/LandingPage.jsx` 외 7개 공개 페이지 | footer 하단 고정 — `flex flex-col` + `flex-1` 패턴 적용 |

> 공개 페이지 8개: `LandingPage`, `ServicesPage`, `HowItWorksPage`, `AboutPage`, `ContactPage`, `RecruitmentDashboard`, `TermsPage`, `PrivacyPage`

## 빌드 명령

```bash
npm run build
```

빌드 완료 후 아래 3가지를 서버에 동시 업로드:
1. `dist/index.html` → `www/index.html`
2. `dist/assets/` → `www/assets/`
3. `dist/locales/` → `www/locales/`
