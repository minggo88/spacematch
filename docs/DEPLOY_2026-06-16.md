## [2] 팝업 등록 오류 수정 (`/admin/popups`)

**증상**: 관리자 팝업 등록 시 항상 오류 발생 (이미지 유무 무관)

**원인 1 — uncaught exception**: `ALTER TABLE` 실행 코드가 `catch (PDOException $e)` 블록 내부에 있었음. 해당 `exec()`이 실패하면(MySQL < 5.7의 JSON 타입 미지원 등) 예외가 최상위로 전파 → PHP fatal error → 빈 응답 or 비(非)JSON 응답 → 프론트엔드 `res.json()` parse 실패 → 오류 토스트

**원인 2 — finfo_open 오류 처리 미흡**: 이미지 업로드 시 `finfo_open()`이 false를 반환하거나(fileinfo 확장 비활성), PHP 8.x에서 TypeError를 던질 경우 MIME 검증 전체가 깨짐

**조치**:
- `ALTER TABLE` 호출을 중첩 try-catch로 감싸 uncaught exception 방지
- JSON 타입 미지원 시 LONGTEXT로 폴백 (`translations` 컬럼)
- `finfo_open()` 전에 `function_exists('finfo_open')` 및 반환값 false 체크 추가
- `mime_content_type()` 폴백 추가 (finfo 미사용 환경 대비)
- MIME 검증 실패 시에만 오류 반환하도록 변경 (MIME 판별 불가 시에는 업로드 허용)

**수정 파일**:
- `public/api/popups/popups.php`
- `dist/api/popups/popups.php`

**배포 경로**: PHP만 수정 → `dist/api/popups/popups.php` FTP 업로드
