## 2. /admin/users/23 상세페이지에 입점신청 내역이 안 보이는 문제

**증상**: `https://spacematch.net/admin/users/23` 같은 관리자 유저 상세페이지에서, 셀러가 입점신청한 내역이 표시되어야 하는데 비어 있음.

**원인**: `get_user_detail.php`가 `applications` 테이블에서 신청 내역을 조회할 때, `seller_id` 컬럼이 존재하면 무조건 `WHERE a.seller_id = ?`만 사용했음. 그런데 실제 신청 레코드는 `user_id`에 값이 들어가고 `seller_id`는 NULL인 경우(레거시/일반 케이스)가 많아 매칭이 전혀 안 됨. 같은 문제를 이미 겪었던 `public/api/applications/get_applications.php`는 `COALESCE(NULLIF(a.user_id, 0), NULLIF(a.seller_id, 0))`로 두 컬럼을 모두 매칭하도록 되어 있었는데, `get_user_detail.php`만 이 패턴이 빠져 있었음.

**조치**: `get_user_detail.php`의 매칭 조건을 `a.{$app_col} = ?` → `COALESCE(NULLIF(a.user_id, 0), NULLIF(a.seller_id, 0)) = ?`(seller_id 컬럼 있을 때) / `a.user_id = ?`(없을 때)로 변경 — `get_applications.php`와 동일한 패턴.

**변경 파일**:
- `public/api/users/get_user_detail.php`, `dist/api/users/get_user_detail.php` (동일 내용 미러링)

**배포 경로**: PHP 1개 파일 → `www/api/users/get_user_detail.php` FTP 업로드.
